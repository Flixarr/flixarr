# Security

## Reporting a problem

Please don't open a public issue for security problems. Report them privately instead:
[report a vulnerability](https://github.com/Flixarr/flixarr/security/advisories/new).

Include what you found, how to reproduce it, and the Flixarr version (Settings, About). You'll get a reply, and a fix is made before any details are made public.

## Supported versions

Flixarr is in early development. Only the newest release gets fixes.
